# Propath Unified Job Portal 🚀

Propath Unified Job Portal is a modern, full-featured web application designed to bridge the gap between job seekers and employers. Built with React and powered by Vite, it offers a seamless, responsive experience with real-time data persistence using LocalStorage.

## ✨ Features

### 👥 For Candidates
- **Role-based Authentication**: Secure login and registration.
- **Job Discovery**: Browse through diverse job listings with ease.
- **Easy Application**: Submit applications for your dream jobs with just a few clicks.
- **Application Tracking**: Keep track of all your submitted applications in one place.

### 🏢 For Employers
- **Job Management**: Create, edit, and delete job postings effortlessly.
- **Applicant Tracking**: View and manage candidates who have applied to your listings.
- **Dashboard Overview**: Get a bird's-eye view of your active postings.

### 🛠️ Technical Highlights
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views using Tailwind CSS.
- **Dynamic Animations**: Smooth transitions and micro-interactions powered by Framer Motion.
- **State Management**: Robust data handling using React Context and LocalStorage.
- **Modern UI**: Sleek, premium interface using Lucide React icons.

## 🚀 Getting Started

To run this project locally, follow these simple steps:

### Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shwetapandya31/Propath_Unified_Job_Portal.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Propath_Unified_Job_Portal
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:3000`.

## 💻 Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion (Motion)
- **Routing**: React Router DOM
